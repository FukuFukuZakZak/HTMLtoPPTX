# HTMLtoPPTX

**完全ローカル・CDN非依存** で動作する、HTMLスライドから編集可能なPowerPoint（`.pptx`）ファイルへの一括変換ツールです。

---

## 概要

生成AIやWebテクノロジーで作成されたHTMLスライドを、レイアウトやデザインを保ちながら **編集可能なPowerPointスライド（.pptx）** へ変換します。

ネットワーク接続が制限された環境や、セキュリティ要件により外部クラウド/CDNが利用できない **ローカル（イントラネット）環境** での利用を想定して開発されています。すべてのスクリプト・ライブラリ・フォントがアプリケーション内に完全ローカル同梱されており、外部通信を一切行いません。

---

## 主な特長

1. **完全ローカル処理（外部CDN非依存）**
   - 外部インターネットへのリクエストは一切発生しません。
   - 外部CDNやサードパーティサーバーへデータを送信しないため、機密情報を取り扱う環境でも安心して利用できます。

2. **編集可能なPowerPointオブジェクトとして変換**
   - 単なる画面キャプチャ（画像化）ではなく、テキストボックス・段落・フォントサイズ・図形・背景・埋め込み画像をPowerPointの編集可能要素として出力します。

3. **多様なアスペクト比とマルチページに対応**
   - **16:9 プレゼンテーション** スライド
   - **A4横・A4縦** ドキュメント形式
   - HTML内のページサイズを自動検出して適したPPTXを出力（混在時は選択統合または分割保存可能）。

4. **2つの起動モード（スタンドアロン GUI / イントラネット Webサーバー）**
   - **スタンドアロンモード**: Windows Edge WebView2を利用した単体GUIアプリとして起動。
   - **Webサーバーモード**: 社内・組織内のイントラネットサーバー上で常駐し、複数ユーザーがブラウザから利用可能。

5. **HTML簡易補正 & プレビュー機能**
   - 終了タグの欠損など、破損したHTML構造をローカルで自動修復する「簡易補正」機能を搭載。
   - リアルタイムプレビューとUndo/Redoに対応。

---

## 動作環境

- **対応OS**: Windows 10 / 11 (x64)
- **スタンドアロンモード**: Microsoft Edge WebView2 Runtime（Windows 10/11には通常標準搭載）

---

## 使い方

### 1. アプリの起動

`HTMLtoPPTX.exe` を実行します。

- 初回起動時は **スタンドアロンモード（専用画面）** で開きます。
- 画面右上の **歯車アイコン（アプリ設定）** から起動モード（スタンドアロン / Web）やポート番号を変更できます。

### 2. HTMLの変換

1. 変換したい `.html` ファイルをドラッグ＆ドロップするか、テキストエリアに直接HTMLコードを貼り付けます。
2. 「**PPTXへ変換**」ボタンをクリックします。
3. 変換完了後、「**ZIPを保存**」ボタンから生成された `.pptx` ファイルを含むZIPアーカイブをダウンロードします。

## 開発・ビルド方法

ソースコードからビルドする場合は、Go および Node.js 環境が必要です。

### 必須環境
- Go 1.22 以上
- Node.js 20 以上

### ビルド手順

```bash
# 依存関係のインストール
npm install

# 簡易補正モジュールおよびマニュアルのビルド
npm run build:repair
npm run build:manual

# Windows用GUIバイナリのビルド
go build -ldflags="-H windowsgui" -o HTMLtoPPTX.exe .
```
