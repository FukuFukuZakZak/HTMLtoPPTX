# How to use 操作マニュアル

アプリの共通ヘッダーにある「How to use」から別タブで開けます。入力中のHTMLを保持したまま、操作画面と見比べられます。

単独で閲覧する場合は、再生成した `Howtouse.html` をブラウザーで開いてください。画像・スタイル・操作用スクリプト・練習用HTMLを内包しているため、このHTML単体でオフライン閲覧・練習用ファイルの保存ができます。`操作練習.html` も別ファイルとして同梱しています。

ユーザーが画面を見ながら操作するための、11章のマニュアルです。目次・前へ／次へ・画面画像の拡大に対応しています。動画・音声・自動再生は含みません。内容は2026年9月7日にユーザー承認済みです。マニュアルはアプリの実行ファイルに内蔵され、インターネット接続は不要です。

## マニュアルの方針

- 初めて使う人が、ボタンの場所と次の操作を判断できるか。
- 基本手順と、必要なときだけ使う補正・追加表示の説明が分かりやすいか。
- 1画面の文章量、画面画像の大きさ、章の分け方が適切か。

## 動画にする際の構成

各章の見出しを場面名、「操作すること」を実演順、「ここまでできればOK」を終了時の確認に使う想定です。基本操作（1〜3・6〜7章）、必要時の操作（4〜5章）、個別に見返す内容（8〜11章）に分け、アプリから必要な章を選べる形を想定しています。動画制作は今後の別工程です。現在は、承認済みのマニュアルをアプリから閲覧できます。

## 作成根拠・再生成

- 画面は `dist/html-repair-20260906/HTMLtoPPTX.exe`（製品コミット `2139b95`）をMicrosoft Edgeで起動し、専用の操作練習用HTMLを使って撮影しました。
- 貼り付け、1件の閉じタグ補正、2ページのPPTXへの変換、ZIPダウンロードを実操作で確認しました。PowerPointでの最終確認はユーザーの操作手順として記載しています。このマニュアル作成時にMicrosoft PowerPointを起動して検証したものではありません。
- 画像原本と注目箇所の座標：`assets/`。注目枠はマニュアル側に重ねています。アプリ画面の文言は変更していません。
- 内容：`build-manual.cjs`、表示：`manual.css`、操作：`manual.js`。
- 再生成：リポジトリのルートで `npm run build:manual`。単独HTMLと `web/howtouse/` の組み込み用HTML・CSS・JS・画像を生成します。単独HTMLは生成物としてGit管理対象外です。
- アプリ版では既存のCSPに合わせてCSS・JSを同じ配信元の別ファイルにしています。CSPの緩和や外部サービスは使いません。
- 組み込み検証：`NODE_PATH` にPlaywrightの場所を設定し、`node scripts/howtouse-acceptance.cjs <起動中のアプリURL>`。
- アプリのラベル・挙動は `web/index.html`、`web/app.js`、`PROJECT_STATUS.md` と照合しています。
