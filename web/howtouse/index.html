01 / 11　基本の操作

「HTMLコードを貼り付ける」を押す

HTMLのコードを持っている場合は、ここから始めます。

操作すること

  1. HTML → PowerPoint の画面を開きます。
  2. 「HTMLコードを貼り付ける」を押します。

ここまでできればOK

HTMLエディターが開き、左に入力欄、右にプレビューが表示されます。

HTMLファイルを持っている場合は、目次の「ファイルから変換」をご覧ください。

ファイルから変換する手順へ

02 / 11　基本の操作

左の欄に、HTMLを貼り付ける

AIなどで作成したHTMLコード全体をコピーしておきます。

操作すること

  1. 左側の「HTMLコード」欄をクリックします。
  2. Ctrl + V でHTMLコードを貼り付けます。

ここまでできればOK

右側のプレビューが自動で更新されます。

文章だけでなく、HTMLのコード全体を貼り付けてください。画面を再読み込みしたり閉じたりすると入力内容は消えるので、元のコードは残しておきます。

操作練習用HTMLを保存

練習用ファイルは「ファイルから変換」の手順で利用できます。

03 / 11　基本の操作

ページを切り替えて、細部まで確認する

最初はページ全体が枠に収まります。右側上部の操作で確認します。

操作すること

  1. 左右の矢印、またはページ選択で、確認するページを表示します。
  2. ＋で拡大し、マウスでつかんでドラッグすると表示位置を動かせます。
  3. −で縮小するか、「全体表示」でページ全体に戻します。

ここまでできればOK

文字・配置・画像を各ページで確認できたら「PPTXへ変換」に進めます。

プレビューを選択中は、＋／−で倍率、0で全体表示、矢印キーで移動、Page Up／Downでページを操作できます。区切りを検出できないHTMLは文書全体を表示します。スクリプトによる追加内容とPowerPointでの見た目は、変換後のPPTXで確認してください。

問題がなければ、変換へ進む

04 / 11　必要に応じて

表示が崩れたら「簡易補正」

HTMLの一部に閉じタグの抜けなどがある場合に使います。

操作すること

  1. 「HTMLコード」欄の右上にある「簡易補正」を押します。
  2. 補正結果の行番号を押すと、追加したタグへ移動します。左端の行番号と、色・下線が付いたタグを確認します。
  3. 戻したいときは入力欄をクリックし、Ctrl + Z を押します。

ここまでできればOK

補正した内容がコードとプレビューに反映されます。折り返し部分は同じ行番号です。Ctrl + Y でやり直せます。

編集やCtrl + Z／Ctrl + Yで色付けは解除されます。コード枠の除去は結果欄に表示します。すべての崩れが直る機能ではありません。補正できない場合や確認が必要な場合は、表示された案内を読み、元のHTMLを見直します。

05 / 11　必要に応じて

グラフやメニューが不足するとき

HTMLを開いた後に追加される内容は、変換時の設定で反映します。

操作すること

  1. まず、通常の設定（オフ）で確認します。
  2. 自分で作成したHTMLなど、作成元を確認できる場合にオンにします。
  3. PPTXへ変換し、出力したファイルで追加内容を確認します。

ここまでできればOK

HTML内のプログラムで追加される内容が、変換対象になります。

オンにしてもプレビューには反映されません。外部から読み込むプログラム・画像などは反映されない場合があります。作成元が分からない場合や迷う場合はオフにします。

06 / 11　基本の操作

「PPTXへ変換」を押す

確認が終わったら、右上のボタンから変換します。

操作すること

  1. 右上の「PPTXへ変換」を押します。
  2. 表示される変換状況を確認し、完了を待ちます。

ここまでできればOK

変換が終わると「ZIPを保存」が表示されます。

変換中は画面を閉じたり再読み込みしたりしないでください。中止するときは、変換状況に表示される「キャンセル」を押します。

07 / 11　基本の操作

ZIPを保存し、PPTXを開く

変換が完了したら、保存まで行います。

操作すること

  1. 「ZIPを保存」を押します。保存先はブラウザーの設定によって異なります。
  2. 保存したZIPを右クリックし、「すべて展開」で取り出します。
  3. 展開したフォルダー内の .pptx をPowerPointで開きます。

ここまでできればOK

文字・図形を編集できるPowerPointファイルとして使えます。画像など、一部は画像として入ります。

最後にページ数、文字のはみ出し、画像、フォントを確認してください。貼り付けたHTMLにタイトル（<title>）があれば、ZIP・PPTX名に使います。タイトルがない・空の場合は「貼り付けHTML」を使います。長い名前や使用できない文字は調整します。向きが混在する場合は複数ファイルになります。

08 / 11　別の操作・困ったとき

HTMLファイルを選んで変換する

保存済みの .html / .htm ファイルは、そのまま読み込めます。

操作すること

  1. 最初の画面で「ファイルを選択」を押します。枠へのドラッグ＆ドロップも使えます。
  2. ファイルを選び、表示されたファイル名・件数を確認します。複数選択もできます。
  3. 必要な設定を確認し、「PPTXへ変換」→「ZIPを保存」と進みます。

ここまでできればOK

HTMLごとのPPTXが、1つのZIPにまとまります。

エディターから戻るときは左上の「ファイル選択へ」を押します。ファイル選択画面にはプレビューや簡易補正はありません。

保存後の開き方を確認する

ページサイズは自動で判定される

説明用の例です。ファイル名は読み込んだHTMLによって変わります。

操作すること

  1. 画面でサイズを指定する操作はありません。
  2. A4縦・横が混在する場合は、ZIPの中に向き別のPPTXが作られます。
  3. 出力したPPTXを開き、意図した向きになっているか確認します。

ここまでできればOK

同じ向きのページは、元の順序でまとまります。

PowerPointは1つのファイル内で異なるページサイズを混在できません。1つにまとめたい場合は、統一するサイズを決めてPowerPointで調整してください。

10 / 11　別の操作・困ったとき

見やすいテーマを選ぶ

画面右上から明るさやデザインを変更できます。

操作すること

  1. 右上の「ライト」「ダーク」「システム」で明るさを選びます。
  2. 歯車を押すと「標準」「8bit」のデザインを選べます。
  3. 選んだら、右上の × で設定を閉じます。

ここまでできればOK

選択はすぐに反映され、同じブラウザーに保存されます。

テーマはアプリ画面の見た目を変えます。入力したHTMLの配色や、出力するPPTXの配色は変わりません。

11 / 11　別の操作・困ったとき

困ったときは、ここを確認

症状を選ぶと、確認する場所と次の操作が分かります。

「PPTXへ変換」を押せない

HTMLコードが空になっていないか、またはHTMLファイルを選択できているか確認します。変換中の場合は完了を待ちます。

HTMLを貼り付ける
プレビューが空白、または表示が崩れる

HTMLコード全体を貼り付けたか確認します。「簡易補正」を試し、結果とプレビューを見直します。外部画像やプログラムで表示する内容は、プレビューに出ない場合があります。

簡易補正の手順へ
画像やグラフが出てこない

プログラムで追加する内容は「追加表示される内容も反映する」を確認します。外部参照の画像やフォントは反映されない場合があるため、HTMLの作成者に、必要な素材をHTML内に含められるか確認します。

追加表示の設定へ
変換エラーが出る

画面のエラーメッセージを確認します。対応するスライドやA4ページの構造がないHTMLは変換できません。複数ファイルの場合は1つずつ試して対象を絞り、HTMLの作成者へメッセージと対象ファイルを伝えます。

ファイルから変換の手順へ
保存したPPTXが見つからない

「ZIPを保存」を押したか確認し、ブラウザーのダウンロード一覧と保存先を確認します。ZIPを展開すると、中にPPTXが入っています。

保存と展開の手順へ
PowerPointで文字や配置がずれる

利用できるフォントやHTML表現の違いにより、出力が元の表示と異なる場合があります。PowerPoint側でフォント・文字サイズ・配置を調整し、編集後のファイルを保存します。
