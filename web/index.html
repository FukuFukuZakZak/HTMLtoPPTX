オンにすると、HTML内のプログラム（JavaScript）をこのツールの隔離領域で実行します。

オンにしてよい例：自分で作成したHTML、庁内で作成され、作成元を確認できるHTML。

対応するHTML・出力について

対応するHTML

.slide、またはA4横・A4縦と判断できるページを含むHTMLに対応します。A4は @page の size またはページ要素の寸法から判定します。

A4の縦・横が混在する場合

ページごとに向きを判定し、縦・横別のPPTXを作成します。PowerPointでは1つのファイル内に異なるページサイズを混在できません。1つにまとめる場合は、出力後にPowerPointで手動統合してください。

貼り付け変換・出力について

貼り付けたHTMLにタイトル（<title>）がある場合は、その内容をZIP・PPTXのファイル名に使います。タイトルがない・空の場合は「貼り付けHTML」を使います。長い名前やファイル名に使えない文字は調整します。外部ファイルを参照する画像やフォントは反映されない場合があります。

16:9・A4縦・A4横のページサイズを自動判定します。A4の縦・横が混在する場合は向き別のPPTXをZIPにまとめます。1つにまとめる場合はPowerPointで手動統合してください。

入力内容はこのPC内だけで処理されます。再読み込みや画面を閉じると入力内容は消えます。
