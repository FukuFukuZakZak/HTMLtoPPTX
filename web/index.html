向き別に出力後、手動で統合

  1. ページごと向きを判定
  2. 縦・横別PPTXを生成
  3. PowerPoint手動で統合

PowerPointでは1つのファイル内に縦向きと横向きを混在できません。生成された縦・横のPPTXは、変換後に手動で1つへ統合してください。

  • .slide、またはA4横・A4縦と判断できるページを含む
  • A4は @page の size またはページ要素の寸法から判定
  • 読み込み後に追加表示される内容は、作成元を確認できるHTMLに限り任意で反映できます
HTML

?この設定について

オンにすると、HTML内のプログラム（JavaScript）をこのツールの隔離領域で実行します。

オンにしてよい例 自分で作成したHTML、庁内で作成され、作成元を確認できるHTML

オフにする例 メール添付や外部サイトから取得したHTML、作成元が分からないHTML、判断に迷うHTML

オンの場合も外部通信は遮断されます。
